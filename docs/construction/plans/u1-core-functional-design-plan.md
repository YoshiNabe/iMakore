## 確認質問

### Question 1: ブラウザ再起動時のセッション復元
ブラウザを閉じて再度開いたとき（または PC を再起動したとき）、作業中（ACTIVE）だったセッションをどのように扱いますか？

A) **セッションを復元する** — `startTimestamp` と `activeProjectId` を localStorage に保存。再起動後も `Date.now()` で正確な経過時間を復元し、作業中のプロジェクトのボタンがアクティブな状態で再開する
B) **リセットする（IDLE 状態から開始）** — 再起動後は常に始業前の状態から始める。シンプルで意図しないタイマー継続を防ぐ
C) Other (please describe after [Answer]: tag below)

[Answer]: A

---

### Question 2: 深夜 0 時をまたいだアクティブセッション
アプリを開いたまま（または再起動後にセッション復元した場合）、深夜 0 時をまたいで作業を続けたとき、どのように処理しますか？

A) **0 時をまたいだら即時ロールオーバー** — タイマーの毎秒更新のタイミング（最大 1 秒以内）で前日分の累積を確定・保存し、当日の累積カウンターをリセットする。作業は継続中（ボタンはアクティブのまま）
B) **次のユーザー操作時にロールオーバー** — 次にボタン操作・終業・または翌日のアプリ起動時に前日分を確定する。深夜作業中は 0 時をまたいでも手動操作があるまで集計確定しない
C) Other (please describe after [Answer]: tag below)

[Answer]: B

---

### Question 3: プロジェクト削除時の過去履歴
登録済みプロジェクトを削除したとき、そのプロジェクトの過去の稼働時間記録（カレンダーに表示される日次データ）をどうしますか？

A) **履歴を保持する** — 削除後もカレンダーの日次記録には稼働時間が残る。表示上は「[削除済み]」のラベルで示す（過去実績が消えない）
B) **履歴も削除する** — プロジェクトを削除すると関連するすべての日次記録から該当プロジェクトの時間も削除される（シンプル・すっきり）
C) Other (please describe after [Answer]: tag below)

[Answer]: A

### Question 4: プロジェクト数とボタン配置
画面に表示するプロジェクトボタンの上限と配置を教えてください。

A) **上限なし・縦スクロール** — ボタンを縦に並べ、多い場合はスクロールで対応する
B) **上限なし・グリッド配置（2 列）** — ボタンを 2 列グリッドで配置し、多い場合はスクロールで対応する
C) **上限あり（最大 10 件程度）** — 多くなりすぎないよう登録上限を設ける。上限超過時は追加不可のメッセージを表示する
D) Other (please describe after [Answer]: tag below)

[Answer]: A
