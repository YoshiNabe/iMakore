# iMakore — イマコレ

今どのプロジェクトの業務を行っているかをボタン一つで記録し、始業から終業までの稼働時間を可視化する Web アプリ。

## 機能

- プロジェクトボタンを押すだけで稼働時間を記録（リアルタイム表示）
- 当日累積時間を各ボタンに表示
- 日次の集計を内蔵カレンダーで確認
- データはブラウザの localStorage に保存（オフライン対応）
- セッション復元（ブラウザを閉じて再起動しても作業中の状態を復元）

## 使い方

1. `始業` ボタンを押して作業を開始する
2. 取り組むプロジェクトのボタンを押す（切り替えも同様）
3. 作業終了時は `終業` ボタンを押す
4. メニュー（≡）からプロジェクトの追加・削除・カレンダー表示が可能

## ローカルで開く

ビルド不要。`index.html` をブラウザで開くだけで動作します。

```
# クローン後にそのまま開く
open index.html        # macOS
start index.html       # Windows
```

> **Note**: ES Modules の制約上、`file://` プロトコルでは動作しない場合があります。
> ローカルサーバーを使用してください。
>
> ```
> npx serve .
> # または
> python3 -m http.server 8080
> ```

## GitHub Pages へのデプロイ

1. このリポジトリを GitHub に push する
2. リポジトリの Settings → Pages → Source を `GitHub Actions` に設定する
3. `main` ブランチへの push で自動デプロイが実行される
4. `https://<username>.github.io/iMakore/` でアクセス可能になる

## テストの実行（任意）

```bash
npm install

```

## データについて

- すべてのデータはブラウザの `localStorage` に保存されます
- サーバーへの送信は一切行いません
- データは 2 年間保持され、それ以降は起動時に自動削除されます
